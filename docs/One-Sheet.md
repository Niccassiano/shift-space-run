# One Sheet — Shift Space Run

**Gênero:** Stealth / Plataforma 2D
**Plataforma:** PC (Windows)
**Engine/Tecnologia:** C + Allegro 5

## Pitch

Em *Shift Space Run*, você se infiltra em salas vigiadas para recuperar
fragmentos de informação, usando furtividade para passar despercebido e
aprendendo curiosidades reais pelo caminho.

## Pilares de design

1. **Furtividade recompensadora** — mover-se com cuidado (Shift) deve ser
   tão viável quanto correr, mas mais seguro.
2. **Aprendizado leve** — cada sala entrega um fato curioso ao final,
   sem interromper o ritmo do jogo.
3. **Progressão por salas** — cada sala tem identidade visual e um tema
   de curiosidade próprio.

## Loop de jogo

Entrar na sala → explorar e coletar fragmentos → evitar detecção →
concluir a sala → ver o card "Você sabia?" → avançar para a próxima sala.

## Escopo do protótipo

- Sala 1 completa (cenário, colisão, cartazes, fragmentos, vidas, HUD).
- Demais salas e sistemas a definir conforme o desenvolvimento avança.
